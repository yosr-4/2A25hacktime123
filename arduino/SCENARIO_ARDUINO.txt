HACKTIME - SCÉNARIO ARDUINO DU MODULE « GESTION DES COMPÉTITIONS »
=====================================================================
« Borne d'affichage des compétitions » (passe par la base Oracle)
Composants : écran LCD 16x2 I2C + 2 boutons. Pas de buzzer, pas de LED.

1. OBJECTIF
  Une borne affiche les compétitions enregistrées dans Oracle et permet de
  changer leur statut avec un bouton. Le changement est enregistré dans Oracle.

2. FONCTIONNEMENT
  - Ligne 1 du LCD : nom de la compétition.  Ligne 2 : son statut.
        HACKATHON IA
        PLANIFIEE
  - Bouton SUIVANTE : compétition suivante.
  - Bouton STATUT   : PLANIFIEE -> EN COURS -> TERMINEE (puis de nouveau PLANIFIEE).
    Le nouveau statut est enregistré dans Oracle, puis le LCD, le tableau et
    les statistiques de l'application sont mis à jour.

3. COMMUNICATION ARDUINO - QT - ORACLE
  Arduino ne parle pas directement à Oracle :
   1. Arduino <-> Qt : port série USB, 9600 bauds (classe Arduino).
   2. Qt lit les compétitions dans Oracle (Competition::lister : SELECT).
   3. Qt envoie à Arduino : C|NOM|STATUT
   4. Bouton STATUT : Arduino envoie S à Qt.
   5. Qt fait l'UPDATE dans Oracle (Competition::changerStatut).
   6. Qt relit Oracle et renvoie C|NOM|NOUVEAU STATUT.
   7. Le LCD affiche le nouveau statut.
  Bouton SUIVANTE : Arduino envoie N, Qt renvoie la compétition suivante.

4. COMPOSANTS
  - Arduino Uno (ou clone CH340)
  - Écran LCD 16x2 avec module I2C
  - 2 boutons poussoirs (SUIVANTE, STATUT)
  - Câble USB et fils Dupont
  - Boîtier : boîte en carton recyclée (trous pour l'écran et les boutons)

5. CÂBLAGE
  LCD SDA -> A4     LCD SCL -> A5     LCD VCC -> 5V     LCD GND -> GND
  Bouton SUIVANTE : D2 et GND
  Bouton STATUT   : D3 et GND
  Boutons en INPUT_PULLUP (pas de résistance externe).

6. CONFIGURATION ET TEST
  a) Oracle : la base hackathon doit contenir des compétitions (table COMPETITION).
  b) Arduino IDE :
     - Outils > Gérer les bibliothèques > « LiquidCrystal I2C » (Frank de Brabander) > Installer
     - Ouvrir arduino/borne_competitions/borne_competitions.ino
     - Outils > Type de carte : Arduino Uno ; Outils > Port : le port COM de la carte
     - Téléverser. Le LCD affiche « HACKTIME / EN ATTENTE PC... »
     - FERMER Arduino IDE (le port série doit être libre pour Qt)
  c) Qt : installer « Qt Serial Port » (Qt Maintenance Tool > Qt 6.7.3 > Qt Serial Port).
     Le .pro contient : QT += serialport
  d) Lancer HackTime carte branchée, se connecter (hacktime123 ou yosr123) :
     le LCD affiche la première compétition d'Oracle.
  e) Test : SUIVANTE -> compétition suivante ; STATUT -> statut suivant,
     vérifiable dans SQL Developer : SELECT NOM, STATUT FROM COMPETITION;
  Survol de la cloche 🔔 de la page Compétitions : indique si la borne est connectée.

7. OÙ EST LE CODE
